# Truth

A personal research project to deconstruct and reconstruct Christian faith through data, scholarship, and primary sources.

> I am going to war with my own preconceived beliefs. This repository is the battlefield.

## Structure

| Directory | Purpose |
|-----------|---------|
| `sources/` | Primary materials: transcripts, book notes, academic papers |
| `notes/` | Analysis, synthesis, and open questions |
| `canvases/` | Visual mind maps (Obsidian Canvas) |

## How to Use

This repository is designed as an **Obsidian vault**. Clone it, open it in [Obsidian](https://obsidian.md), and you'll get:

- Full wikilink navigation between notes
- Tag-based organization (`faith/yahweh`, `faith/deconstruction`, `source/transcript`, etc.)
- Graph view showing connections between sources, analysis, and questions
- Canvas mind maps for visual exploration

If you're just browsing on GitHub, start at `Home.md`.

## Philosophy

1. **Primary sources first.** Evidence over commentary.
2. **Scholarly consensus where it exists.** Understand disagreements.
3. **Steelman every position.** Best version of every view.
4. **Follow the data.** Even when it's uncomfortable.
