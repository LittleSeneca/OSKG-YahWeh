Calibrate your note depth against these existing benchmarks. These represent notes written at different quality levels across multiple books. Aim for the "thorough" range; "compressed" notes are flagged for follow-up expansion.

## Compressed (6-10 KB)
- Notes where session fatigue visibly reduced depth. These still follow the format but have fewer claims, less evidence detail, and shorter assessments. Flagged for expansion when the book is revisited.
- **Concrete example:** Smith Origins Ch7-9 were initially written at 17-22KB (4-5 claims) by the main agent vs. 33-34KB (7-8 claims) by sibling subagents — a 1.5-2x compression ratio. The subagent versions were kept; the main agent's compressed versions were deleted.

## Key Ratios
- Source text: ~1,000 lines per substantive chapter section in a typical academic monograph
- Note output: 15-25KB of note per ~1,000 lines of source text = thorough
- Below 10KB per ~1,000 lines = compression suspected
- Below 6KB = definitely under-read — go back

## Session Fatigue Pattern
The taper is real and predictable: early notes in a session are largest, later notes shrink as energy and attention decline. Counter by:
- Pacing: stop after 5-6 notes, resume fresh
- The periodic retrospective (every 3-4 notes) catches the taper before it goes too far
- At session end, flag thin notes honestly rather than pretending they're complete
